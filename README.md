# Real-Time Chat Application

A real-time chat application built while learning **Node.js, Express.js, and Socket.IO**.

The main purpose of this project is to understand how real-time communication works between multiple clients and a backend server.

The application allows multiple users to join a common chat, communicate with each other in real time, see active users, and receive notifications when users join or leave.

## 🚀 Features

- Real-time messaging
- Multiple users can communicate with each other
- Username-based messaging
- Active users list
- User join notifications
- User leave notifications
- Disconnect detection
- Join and Leave chat functionality
- Messages display the sender's username
- Press Enter to send messages
- Terminal/CRT-style frontend
- Responsive frontend
- Real-time communication using Socket.IO
